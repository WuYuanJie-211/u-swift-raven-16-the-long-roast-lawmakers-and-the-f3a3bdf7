A single original satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF: Congress spent six months writing the law that will govern artificial intelligence, then left it as a Word document — because the only person in the building who knew how to save it as a PDF retired in 2019.

Run `node main.ts` to write the entry to /output/entry.txt.
